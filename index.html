📋 How to Get Your Google API Credentials (Free, 5 min)
1
Go to console.cloud.google.com and sign in with srajbk356@gmail.com
2
Click "Select a project" → "New Project" → Name it TutorDesk → Click Create
3
In the left menu: APIs & Services → Library → Search for "Google Drive API" → Click it → Click Enable
4
Go to APIs & Services → OAuth consent screen → Choose External → Fill: App name = TutorDesk, Support email = your Gmail → Save. Under Test users, add srajbk356@gmail.com
5
Go to APIs & Services → Credentials → Create Credentials → OAuth 2.0 Client ID → Application type = Web application → Under Authorized JavaScript origins, add the URL where you open this file (or http://localhost if local). Copy the Client ID → paste above.
6
Click Create Credentials → API Key → Copy it → paste above as API Key. Restrict it to Google Drive API for security.
7
Click Save & Connect above, then sign in when prompted. TutorDesk will now auto-save every Excel export to srajbk356@gmail.com's Drive in a folder called TutorDesk Backups. ✅
💡 Tip: Once you set this up on one computer, just share the tutordesk_pro.html file with others. They open it and click "Connect Google Drive" — it saves to your Google account automatically. No server needed.
